# Notebook/script starters

This folder includes Colab-friendly Python scripts for the next project stage.

- `02_balance_split_export.py`: merge windowed arrays, subsample benign windows, make 85/10/5 stratified split, save `.npz`.
- `03_training_starter.py`: load saved `.npz`, build CQMLP starter model, create PyTorch `DataLoader`s, run a smoke-test training loop.
